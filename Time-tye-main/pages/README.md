# Telas do Time Tye

As telas do MVP são despachadas por `app.py` para manter autenticação,
permissões e estado da corrida em um único fluxo do Streamlit. Este diretório
fica reservado para a extração futura de cada tela (`home`, `login`, `run`,
`history`, `runners`, `profile` e `settings`) sem alterar as regras de negócio.
